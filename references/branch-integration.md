# 分支反馈的整合方式与适用范围

## 本版依据是什么

v2.1基于v2.0，以及用户指定的Hogan群体报告分支检索记录和该分支产出的12页管理解读修订稿。修订稿能够核对的内容包括：结论—工作表现与影响—数据支撑；HPI群体与差异个体同页；点位标注均值/中位值；HDS实名热力图及分档映射；三栏总结与业务影响。

分支的完整聊天标题、全部逐字对话及“专业团队”参考截图原文未完整恢复。本版不把助手修订稿冒充用户逐字原话，也不把所有改动称为用户已再次确认。以下区分分支可核对要求、主流程延续和本次工程化补充。

## 已提炼并写入通用规则

| 可核对的要求/呈现 | Skill中的落实 | 适用边界 |
|---|---|---|
| 大白话但专业，结合工作表现、协同、推进、交付 | 管理解读写法：结论→行为及一步工作影响→少量依据；建议对应具体任务 | 不是要求所有文字变成口语、问句或培训口号 |
| HPI群体结论与明显高/低于均值的差异个体同页 | 左群体图、右共性、底部差异卡；高低两端有依据时都考虑 | 不固定人员，不把相对差异称统计显著或低能力 |
| 均值/中位值标在折线点位旁 | 单批概览两种统计量直接标点、颜色/线型与图例对应 | 跨批仅均值请求仍只画均值，不机械添中位值 |
| HDS热力图按指定格式展示姓名和四档色调 | 在授权受众内支持实名/缩写/编号模式及可配置显示标签 | 本次实名要求不能扩成以后所有报告均实名，更不能公开真实数据 |
| 总结三栏：可放大的优势／需管理的风险／对应的发展建议 | 管理解读12页模板第11页；底部补正向价值／需要防范 | 不把“第11页”强加所有报告；仅结论任务不加建议 |
| 报告中的姓名缩写有明确纠正 | 运行时读取用户确认映射，用稳定成员ID关联资料 | 真实姓名与映射不写入公共Skill或虚构测试 |

## 延续主流程，不被这次分支覆盖

个人核心画像仍主要用HPI单点和HPI内部组合；HDS、MVPI在各自模块补充。已确认的个人雷达图与位置不重绘。完整群体报告不是个人页合集。跨届对比只在明确请求时做。公开包不含真实分数、人员资料或业务案例。

## 本次新增的工程安排（不是分支原话）

1. 增加`management12`和保留`compact10`两种群体结构，用字段控制而非记死页码。
2. 增加报告计划检查器，检查姓名展示授权、统计量选择和标签映射；它不验证真实授权。
3. 增加结构化解读卡和有限审稿检查器，检查是否漏了场景、行为、影响和依据；它不能判断心理解释是否有效。
4. 将分支反馈分成长期表达原则、可配置版式、仅限本批的信息，避免把一次性要求污染后续批次。

公开包只保留抽象规则和重新构造的条件性示范，不包含该分支原报告、原截图、个人名单、数据、内部文件路径或逐字长段对话。
