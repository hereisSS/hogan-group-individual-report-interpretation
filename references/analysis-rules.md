# 分析规则：来源先行，HPI主导画像，写清工作行为与影响

## 1. 三层含义不能串用

本流程使用用户报告中的HPI（明亮面·日常风格）、HDS（暗面·压力风险）、MVPI（动机·价值偏好）。执行时仍须读取当前报告的量表定义、低分者/高分者倾向、摘要及个人维度解释。

HPI用于理解通常如何做事；HDS用于理解压力、疲惫、无聊等条件下可能过度使用的行为；MVPI用于理解什么容易激发投入、重视怎样的工作环境。它们不是“能力、绩效、动机”的三个可相加得分，也不能彼此抵消。

具体词义以当批报告为准。不能因为量表名字相近就合并：HPI审慎≠HDS谨慎；HPI审慎≠HDS苛求；HPI社交≠MVPI归属；HPI抱负≠MVPI权力。

## 2. 严格区分三种陈述

- 原报告事实：维度分数、分档、报告已经写出的倾向。附文件与页码。
- 本批计算：均值、差值、最大绝对差、按确认分档计算的项数。附计算口径。
- 工作场景推断：跨量表组合可能体现的目标、协作、反馈、决策、承诺、交付行为。写“可能/倾向/需观察”，不能包装成原报告原话或已经发生的表现。

当原报告解释与直觉不一致时，不用通用心理学知识替换。记录差异并回看维度定义及适用条件。外部研究只有在用户明确要求时引入，且与报告解读分开标记。

## 3. 分档只按当前已核对口径

以下是本次已交付个人PPT使用的**项目展示口径**，不是适用于所有Hogan报告版本的无条件标准：

| 量表 | 项目展示分档 |
|---|---|
| HPI / MVPI | 0–25低；26–50中低；51–75中高；76–100高 |
| HDS | 0–39无风险；40–69低风险；70–89中等风险；90–100高风险 |

下一批先对照其报告与用户模板。原模板只写部分区间时不能自行声称剩余区间已获官方认证。若版本/常模/标签有不同，标明冲突并选用经用户明确认可、且与源报告说明相容的口径，不能静默混用。

HDS的“无风险”只是以上展示区间的名称，不表示实际工作风险为零。高风险也不是问题发生概率，更不能据此给人贴负面标签。

## 4. 群体差异≠高低分≠风险

先判断源报告分档，再比较本批均值。一个维度低于群体平均，仍可能位于中高/高区间；某人的最大差异可能是低风险方向，不一定是最重要的业务风险。

群体仅代表本批N人、含本人，不代表公司整体、该职位或人群总体。小样本差异不得称为“统计显著差异”。不跨不同常模或不兼容量表版本机械计算一个均值。不得计算综合能力分、总风险分、人才排名或适岗推荐。

## 5. 核心画像：HPI为主，先组合后概括

以HPI描述个人日常做事方式，优先用HPI内部的单点及组合说明主动性、安排任务、学习和与人合作的特点。选2–3个有解释力的方面，不逐项抄分数，不强行给每个人制造相同的风险。

HDS只在有必要时补充压力状态，MVPI只在有必要时补充投入来源，不再固定用MVPI组成核心画像的第二句。组合不是已验证的数学预测模型：不能把分值相加、抵消或凭组合断言已发生行为。

写法与例子见`writing-style.md`。例如“愿意带头，但更多通过商量推动”同时说明主导意愿和合作方式；比“领导型、亲和型人才”更具体。

## 6. 需关注：场景 → 可能行为 → 工作后果 → 观察重点

每人优先2条最有依据的重点。必须说到工作影响，不能止于“关注反馈开放度”。例如“先答应交付日期，再算人手，可能造成延期；重点看承诺前是否核对工作量和依赖条件”。

没有岗位/绩效材料时，用通用且明确标注的假设场景，不编造实际业务损失、客户问题或冲突。业务后果必须是对应行为的合理一步后果，不把“不愿听取意见”直接夸成“项目失败”。

优点和代价可同时出现，但不强行把风险美化为优势；没有证据不硬凑关注点。

## 7. 三栏内容的职责

| 栏目 | 回答的问题 | 避免 |
|---|---|---|
| HPI 突出特点 | 日常风格中最清晰的特点是什么？ | 把高分翻译为能力强、业绩好 |
| HPI 群体差异 | 相较本批，哪些行为风格更突出？ | 低于均值就判定短板 |
| HPI 低位与关注 | 绝对低位或风格过度使用值得观察什么？ | 无低位时硬凑缺点 |
| HDS 突出倾向 | 最主要的压力倾向和组合是什么？ | 逐维度孤立抄写、贴标签 |
| HDS 群体差异 | 相比本批，压力反应的区别是什么？ | 最大差异等于最高风险 |
| HDS 风险与关注 | 在什么情境关注什么行为？风险项数是否一致？ | 未进入高风险却称高风险；无高分就称绝无风险 |
| MVPI 核心驱动 | 什么回报、价值和环境更易激发投入？ | 科学高=科研能力强，商业高=会做生意 |
| MVPI 群体差异 | 相比本批，更看重或较少依赖什么？ | 价值观优劣评价 |
| MVPI 低位与关注 | 哪类激励不是主要来源，可能出现什么匹配张力？ | 利他低=冷漠；认可低=没上进心 |

## 8. 中文表达校准（均为写法示例，不是任何人的结论）

不写：“这个人创新能力强。”
改为：“对新想法和探索保持兴趣，需结合实际任务观察能否转化为可执行方案。”

不写：“他没有事业心。”
改为：“日常更少主动争取主导位置；是否重视成就，应同时查看价值偏好及实际表现。”

不写：“不听劝，容易导致项目失败。”
改为：“压力下可能更坚持自身判断，需观察收到相反证据时能否及时调整。”

不写：“商业偏好低于群体，所以不懂生意。”
改为：“相较本批，经济回报并非最突出的投入来源；这不直接代表业务理解能力。”

以上改写仍须有当前报告证据，不能作为所有人的万能句。

## 9. 备注中的证据模板

每页备注至少含：使用边界；报告版本及常模；分数/均值/差值；分档来源；核心画像两条依据；需关注两条依据；各栏主要维度的文件名及实际页码；风险项清单；图像版本；异常与未核实项。

页码必须从实际文件读取，不能沿用历史“第4页是总览”等经验值。

## 10. 群体与批次比较

群体分析看均值、中位值、范围、人数与行为组合，不以均值代替个体。跨批次先核对同口径；来源冲突不静默纠正。相同分值或很小差异不能人为解读出明显不同的工作风格。具体规则见`group-analysis.md`。


## 11. 管理解读不等于把风险说得更重

结论、工作价值/代价、数据依据需要相互支持。优势不能只有性格词，风险不能从“一项倾向”跳到“项目失败/人员不合格”。支持方式必须对应行为。HPI差异卡兼顾有依据的高低两端，仍不能替代全体结论或被当作能力排名。

工作解释先记录结构化卡（见analysis-card.example.json）：证据、主要判断、场景、行为、一步影响、观察、条件性说明。写作先后顺序可以调整，但不遗漏依据与影响；脚本只检查字段和少数词语，不证明推断正确。

## 12. 展示标签与量表含义不能混成一件事

用户明确指定热力图称谓/颜色时可按授权样式呈现，但源区间与源标签必须保留在受限方法记录，图例/脚注说明自定义标签。不能在同一报告把两个不同区间都写成同一等级，也不能因改颜色而改变分档统计。见report-options.md。
