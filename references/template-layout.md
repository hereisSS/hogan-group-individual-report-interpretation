# 实际PPT模板与使用规则（1页个人 / 12页管理解读 / 10页兼容）

完整群体分析默认选12页管理解读模板，结构和字段见本文后半部分；10页模板保留兼容。个人模板不变。

## 选择顺序

用户本次指定模板 > 明确指定且可访问的历史模板 > `assets/templates/`内置空白模板。未读取的历史文件不能声称已沿用。内部模板不自动加入GitHub包。

模板均为16:9，13.3333 × 7.5英寸，从空白文档重建；没有原始图像、人员分值、实际业务案例或历史备注。正文、网格和图形可编辑；图表目前为空白结构，不是已完成统计。

## 个人：individual-report-template.pptx，1页

沿用既有个人页区域关系：上方姓名/批次、核心画像、需关注；下方HPI左/HDS中/MVPI右。每个人复制一页，默认不加个人报告封面。

| 区域 | 填入内容 | 稳定对象名 |
|---|---|---|
| 页眉 | 代号、批次 | `person.alias`、`person.batch` |
| 核心画像 | HPI为主的2句人物特点，写组合而非列高分 | `core.text` |
| 需关注 | 约2条场景、行为、工作影响和观察重点 | `focus.text` |
| 三栏标题 | HPI / HDS / MVPI及各自作用 | `HPI.header`等 |
| 雷达图 | 已确认PNG，保持比例和对应位置 | 删除`HPI.radar.*`等占位对象后插入 |
| 相对群体 | 最大绝对差及本人与本批均值 | `HPI.difference`等 |
| 三栏分析 | 特点/群体差异/关注，MVPI第一项为核心驱动 | `{量表}.section0/1/2.body` |
| 页脚 | 群体口径、分档、解释边界、内部使用 | `footer.method`、`footer.internal` |
| 备注 | 来源和页码、原分/均值、组合依据与推断边界 | 不默认放身份映射 |

**雷达图区域（英寸）：**

| 量表 | 左侧x | 顶部y | 最大宽 | 最大高 |
|---|---:|---:|---:|---:|
| HPI | 1.300 | 2.552 | 2.442 | 2.240 |
| HDS | 5.579 | 2.552 | 2.413 | 2.240 |
| MVPI | 9.877 | 2.552 | 2.327 | 2.240 |

按图片长宽比适配到区域内并居中，不把图片拉伸到这四个尺寸。保持确认图片的原始字节，不为了“统一风格”再绘制。区域来自既有个人模板位置；本版清除了原模板重名、越界和历史内容，不复制那些问题。

## 群体：group-report-template.pptx，10页

| 页 | 内容 | 需要输入 | 关键呈现 |
|---:|---|---|---|
| 1 | 封面 | 批次、N、日期、目的 | 不继承旧年份/人数 |
| 2 | 整体画像 | 共性与关注、分布依据 | 两栏：优势 / 工作影响与关注 |
| 3 | 数据概览 | 各量表均值与中位值 | 三栏折线区域，统一刻度 |
| 4 | HPI | 原分/统计、HPI组合解释 | 左雷达，右结论，底部分化 |
| 5 | 团队角色 | 认可公式、角色人数 | 左覆盖雷达，右工作含义和边界 |
| 6 | HDS | 主分、可得子量表原图 | 左雷达，右4类动态重点 |
| 7 | HDS差异 | 个人原分、分档 | 编号热力图 + 共性组合说明 |
| 8 | MVPI | 分值、价值偏好解释 | 左雷达，右任务/环境投入线索 |
| 9 | 工作影响总结 | 场景、行为、后果、观察点 | 场景 / 工作影响 / 观察三栏 |
| 10 | 阅读指南 | 常模、来源、解释及保密边界 | 定义、统计、证据、用途 |

没有角色公式或子量表原图时，不用模板空间当作编造理由。需注明未统计，或按用户要求删相应模块/页。热力图示范6行只是空白布局，实际按N调整，不能误作6个真实受测者；“—”不是0。

## 字段映射与实际编辑

`assets/templates/template-map.json`保存全部文本框名称、页码、坐标、占位文本及个人雷达区域。先用`inspect_pptx.py`读取实际模板；结合名称/坐标/文本/渲染定位，不盲目替换所有同名对象。

折线/雷达/热力图空白区域应替换成确定性绘图或原生可编辑图表。不能把整个PPT做成截图；保留可编辑正文。群体图像若非原生图表，应明确交付形式。

## 成稿与隐私核验

逐页清除所有`[说明]`、`{字段}`、空白图例及模板标识。检查正文、备注、对象名称、图表嵌入数据、文档属性、外链，不仅看可见姓名。新报告输出到仓库外运行目录，不覆盖公共空白模板。

必须实际渲染并检查全部页面；程序坐标检查不是视觉核验。中文不缺字、数值不重叠、文本不越界。具体字体根据获授权环境选用，不将字体文件打包到仓库。

## 重建模板

仅维护模板时安装适当版本的`python-pptx`并运行：
```bash
python scripts/build_templates.py --out "$RUN/new_blank_templates"
```
脚本拒绝覆盖同名现有模板；重建后需要重新目检、更新字段映射和预览。经人工确认后再更新发布哈希清单，不因为哈希变化就自动信任新文件。它不是正式报告自动填充器。


## v2.1 新增：group-management-template.pptx，12页

完整管理解读优先用该模板；保留上文10页模板供compact10或旧调用使用。个人模板区域与原文件不变。新模板同为16:9，从空白构建。

| 页 | 内容和对象前缀 | 与旧版区别 |
|---:|---|---|
| 1 | 封面 | 样本/受众占位，无公司标志 |
| 2 | 整体画像 | 优势与风险都要求行为、影响、证据 |
| 3 | 单批概览 | 均值/中位值直接标点，不改成图下数值表 |
| 4 | HPI；`m4.diff0/1/2` | 左雷达、右共性、底部三张高/低或其他有依据差异卡 |
| 5 | 项目角色 | 保留来源公式说明，不作能力判断 |
| 6 | HDS主量表 | 与子维度拆开，聚焦压力条件和工作影响 |
| 7 | `m7` 子维度三列 | 具体突出点/人数→工作表现→协作交付影响 |
| 8 | `m8` 热力图 | 全量分值表＋四档纵向色带＋观察卡；名称模式按权限 |
| 9 | MVPI；`m9.diff0/1/2` | 共同驱动与差异个体同时呈现 |
| 10 | `m10` 工作观察 | 场景／表现与影响／观察行为／支持方式四列 |
| 11 | `m11` 总结 | 优势／风险／发展建议三栏；底部正向价值／需要防范 |
| 12 | 阅读口径 | 不默认加身份对照，明确授权才另加 |

具体字段保存于`management-template-map.json`。模板热力图的六行和三张观察卡只是占位容量，不是受测者人数或筛选规则；实际按N与可读性增减、分页。色带示意原标签与参考显示标签的区别，不代表新批次已确认分档。

新模板生成：`python scripts/build_management_template.py --out "$RUN/blank_management"`。复制到发布包前逐页渲染、人工审查、更新哈希；不可只运行脚本就声明完成。
