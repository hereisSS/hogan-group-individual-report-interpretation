# 输入清单：给什么，能做什么

## 推荐的一次性提交

每人HPI完整PDF、HDS完整PDF、MVPI完整PDF；可再附摘要用于核验。完整报告通常包含定义、总览和维度解释；实际以文件内容为准，不以固定页数认定完整。

按每人一个文件夹组织最清晰，不强制特定文件名：
```text
本批报告.zip
  P001/
    HPI.pdf
    HDS.pdf
    MVPI.pdf
    摘要.pdf    # 推荐，非硬性必需
  P002/
    ...
```

N人通常为3N份详报，摘要齐全时为4N份。人数按唯一受测者核对；同缩写不自动合并，摘要与详报姓名不同不擅自更正。授权身份核验结束后不要把测试账号保留在共享成稿。

## 必需信息

| 输入 | 用途 | 缺少时处理 |
|---|---|---|
| 处理权限与获准使用的环境/受众 | 确定允许处理和交付范围 | 未明确有权提供的材料不要上传；不擅自外传 |
| 批次/届别、人员代号、期望人数 | 避免串批、漏人和重复 | 年份与人数核实后再成稿，不从旧模板继承 |
| 各主量表分值及可追溯来源 | 作图、计算与复核 | 缺分不填0、不估图、不拿旧数据补 |
| 常模/报告版本/量表名称 | 判断能否一起计算和比较 | 核对源文件；不兼容则拆开 |
| 本次输出范围 | 个人、群体、两者或跨批比较 | 按用户明确请求，不自行增加报告 |
| 群体比较基准 | 当前批次/指定已审核汇总 | 默认为本批N人含本人；历史汇总先确认 |

## 推荐的业务背景

让工作影响写得贴切，推荐给：岗位或工作类型、当前阶段、典型任务、经常合作的对象、最近需要观察的问题、报告给谁看。每项一句话即可，不必提交客户名称、商业机密、具体收入或不相关绩效记录。

没有这些信息时，只能写“例如需求改变、项目延期、跨团队协调”等通用情景，并标明是待验证假设。不会假定是研发、产品、运营或管理岗位，也不捏造工作事件。

## 输入层级与能力边界

| 现有材料 | 可以交付 | 不可以声称 |
|---|---|---|
| 完整详报 + 摘要 + 授权背景 | 核对图、个人与群体解释、工作情景关注 | 证明能力/绩效或保证行为发生 |
| 完整详报，无摘要 | 对照总览与维度页核验后继续 | 未核对却标“多来源一致” |
| 只有完整分值表/清晰分数页 | 分值整理、均值/中位值/范围、核对图 | 完整详报解释、缺失的子维度结论 |
| 只有HPI | HPI日常风格和HPI组合解释 | 补造HDS或MVPI；完整三表报告 |
| 只有两批均值表 | 各维度均值比较 | 反推中位值、人数分布、个体或角色覆盖 |
| HDS主量表，无子维度页 | 主量表风险倾向统计 | 从主分猜满格人数、子量表高低 |

当前`validate_scores.py`针对完整三表JSON；局部HPI任务需明确做单表核验，不把空表填0来绕过该校验器。

## 特定产物还需要什么

**HDS子维度页：**清晰的原始子维度图、格数与定义；确认计数规则和实际可读人数。满4格是曾用过的项目“突出”口径，不是主量表风险等级。看不清写缺失。

**团队角色页：**用户认可的角色公式、阈值及出处。内置文档保留既有项目规则便于复用，但只有确认后才使用；角色并非实际能力或绩效证明。

**跨批对比：**两批完整原分最佳，也可使用双方已确认汇总；分别保留来源、N、版本、时点和计算方法。历史汇总与原分不一致时，不静默替换。

**PPT模板：**没有内部模板时用包内空白模板；要严格沿用某个内部版本，需提供可访问PPTX或明确文件。不要要求上传真实报告当“公共模板”。

## 用户直接填写

见 `assets/input/request-form.md`；机器可读字段示例见 `assets/input/batch-request.example.json`。JSON分值格式见 `references/data-contract.md`；`scores.synthetic.json`全部为虚构测试，不是用户应填写的真实报告。


## 新增：管理解读与版式要求也作为输入

推荐同时说明报告受众、工作阶段、典型任务、最关心的判断/推进/交付/协作问题。已有对话明确说明的内容直接复用，不要求重新填写。没有背景时只用通用假设，不默认有轮岗或管理职责。

可提供认可的“专业团队”文字/截图，用来学习措辞和组织方式；参考内容必须可读，不能从未见截图猜原话。参考图中的人数、分数、角色结论、姓名不进入新分析。

配置：群体management12/compact10/自定义；是否要发展建议；单批均值与中位值或跨批仅均值；身份显示编号/授权缩写/实名；HDS参考图和源区间到显示标签映射。实名需受众权限与已确认姓名映射；公开仓库不接收真实名单。
